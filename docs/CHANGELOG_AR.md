# سجل مراجعة وتطوير V8

## ما كشفته مراجعة الحزمة الأصلية

- Docker كان يشغّل `app.py`، بينما الاختبارات المرفقة كانت تختبر `main.py` ذي قاعدة بيانات ومسارات مختلفة.
- ملف `.env.example` المشار إليه في الدليل لم يكن داخل ZIP.
- دليل التشغيل ذكر 8087 بينما Compose لم ينشر هذا المنفذ.
- العربية والإنجليزية والوضع الفاتح ولوحة الإدارة لم تكن مكتملة.
- نموذج الطلب لم يدعم البريد المنفصل والموعد والمرفقات.
- قاعدة جديدة كانت تُملأ بمشاريع افتراضية داخل `app.py`.
- رفع الصور كان يكتفي بترويسة الملف دون إعادة ترميز.

## الواجهة العامة

- هوية Emerald / Mint / Deep Navy، تكوين Hero جديد ورسم معماري CSS خفيف.
- **IBM Plex Sans Arabic محلي** بأوزان 400/500/600/700، مع الترخيص داخل static/fonts؛ تعديل تباعد العربية وأوزان العناوين.
- العربية RTL والإنجليزية LTR، حفظ اللغة والمظهر واحترام مظهر الجهاز عند أول زيارة.
- الخدمات، البحث في المشاريع، دراسات الحالة، المقالات، طريقة العمل، التقنيات وروابط التواصل.
- إدراج المحتوى من SQLite، دون مشاريع أو مقالات أو إحصاءات مختلقة. نُقلت أوصاف الخدمات الموجودة إلى محتوى أولي قابل للتعديل والحذف، ولا تعود بعد حذفها وإعادة التشغيل.
- نموذج متجاوب بالحقول المطلوبة، ومرفق اختياري واحد PDF أو صورة حتى 5MiB.
- تحسين الهاتف وحل تجاوز العرض بسبب الدائرة المتحركة وحقل مكافحة الروبوتات.
- حالات فارغة وأخطاء اتصال واضحة، وfocus مرئي وlabels ودعم reduced-motion.

## الذكاء الاصطناعي

- محادثة بواجهة جديدة، اقتراحات، مؤشر انتظار، نسخ الرد.
- عرض Markdown آمن بعناصر DOM: عناوين وقوائم وأكواد واقتباسات وتأكيد النص؛ لا يتم تنفيذ HTML من الردود.
- AI Architect بثمانية أقسام، مخطط خطوات مرتب، ونسخ التحليل.
- التحقق من بنية JSON ورفض الردود التي تتضمن تعبيرات مالية معروفة.
- الحفاظ على Webhook chat: message/sessionId والترويسة X-SAMI-AI-KEY والاستجابة reply أو output.
- الإبقاء على Playground والمختبر التعليمي مع توضيح أنه محاكاة وليس تنفيذًا فعليًا.

## الإدارة والخلفية

- لوحة عربية/إنجليزية مع تبويبات ومؤشرات حقيقية من القاعدة.
- CRUD للمشاريع والمقالات والخدمات، حقول لغتين وصور ومشروع منشور/مسودة.
- تعديل نصوص الرئيسية وSEO وروابط التواصل.
- عرض الطلبات والتفاصيل والمرفقات وحالات المتابعة وحالة إشعار n8n.
- جلسات موقّعة، HttpOnly وSecure في الإنتاج، SameSite Strict، فحص Origin وترويسة mutations، وحدّ المحاولات.
- الحفظ قبل إشعار n8n؛ فشل الإشعار لا يفقد الطلب.
- مرفقات العملاء خارج المسارات العامة، وتحميلها عبر endpoint محمي.
- فحص الصور وإعادة ترميزها WebP وإزالة بياناتها الوصفية، وحد أبعاد وحجم.
- ترحيل إضافي لكلا المخططين السابقين، مع استيراد رسائل main القديم مرة واحدة إلى الطلبات والإبقاء على الأصل.
- إغلاق اتصالات SQLite، WAL، وتوحيد main.py على التطبيق نفسه.
- ترويسات CSP وnosniff وframe protection وسياسة وصول للمتصفح.
- SEO وOpen Graph يُنتجان على الخادم من إعدادات المحتوى مع escape، إضافة canonical وrobots وsitemap.

## التشغيل والتسليم

- Docker على 8000 وHealthcheck، دون Host Port في Compose الأساسي.
- override محلي على 127.0.0.1 ومنفذ قابل للتغيير.
- override اختياري لربط Volume موجود باسمه الموثّق فقط.
- `.env.example` دون أسرار، dependencies بإصدارات تم اختبارها، وملف منفصل لاعتمادات الاختبار.
- نسخ احتياطي متسق لـSQLite يشمل الصور والمرفقات، ويرفض الكتابة فوق نسخة موجودة.
- أدلة تشغيل ونشر ورجوع وتقرير اختبارات، وحفظ ملفات المسار القديم للمرجع فقط.

لم يحصل نشر أو تعديل مستودع خارجي أو دمج إلى main أو تغيير دومين أو حذف Volume أو قاعدة بيانات فعلية.
