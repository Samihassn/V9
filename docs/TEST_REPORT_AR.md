# تقرير الاختبارات — 3 نوفمبر 2026

## النتيجة

**15 اختبار Python ناجحًا** على التطبيق الفعلي `app:app` باستخدام FastAPI TestClient وSQLite مؤقتة. فحوص بناء JavaScript النحوي ناجحة. أُجريت مراجعة بصرية في متصفح Chromium للواجهة العامة وشاشة دخول الإدارة.

هذا إصدار مرشح للاختبار على سيرفرك، وليس إثباتًا لنشر إنتاجي أو تدقيق أمني مستقل.

## اختبارات آلية ناجحة

| المجال | ما تم التحقق منه |
|---|---|
| الدخول والجلسات | منع غير المسجل، HttpOnly وSameSite، Secure في وضع الإنتاج، رفض جلسة مزورة/منتهية، الخروج |
| حماية التعديل | رفض Origin خارجي وغياب X-SAMI-Admin، منع تجاوز حد محاولات الدخول |
| إدارة المحتوى | مشاريع ومقالات وخدمات، حقول لغتين، تحديث وحذف وإخفاء المسودات، رفض رابط غير آمن |
| طلبات العملاء | التحقق من البريد والتاريخ، honeypot، حفظ الطلب ومرجعه |
| المرفقات | قبول مرفق PDF اختباري، تنزيل محمي، رفض وصول دون جلسة، رفض ملف SVG |
| الصور | فحص PNG وتحويله فعليًا إلى WebP، رفض بايتات غير صالحة |
| إشعار n8n | فشل تكامل تجريبي لا يفقد الطلب، وتسجيل notification_status=failed |
| عقد المساعد | message/sessionId، reply/output، والتحقق من X-SAMI-AI-KEY عبر HTTP MockTransport |
| أخطاء AI | الرد المفقود وJSON غير الصالح وحالة upstream 500 ترجع 502، غياب الإعداد يرجع 503 |
| AI Architect | ثمانية أقسام منظمة، رفض الرد المالي وغير المطابق، عدم رفض كلمة عربية بريئة بسبب تطابق جزئي |
| ترحيل V7 | حفظ المشاريع من مخطط app القديم ومخطط main القديم، وإمكانية إضافة سجلات بعد الترحيل |
| إعادة التشغيل | حفظ المحتوى والحالات، وعدم تكرار استيراد الرسائل القديمة عبر تشغيلين |
| قواعد جديدة | لا تضاف مشاريع وهمية |
| النسخ الاحتياطي | ملفات القاعدة والصور والمرفقات داخل ZIP، integrity_check=ok، رفض استبدال نسخة موجودة |
| SEO والأصول | escape للنص داخل metadata، canonical وsitemap وrobots، ووجود ملفات الواجهة |

الأمر:

```bash
python -m pytest tests -q
```

ظهر تحذير deprecation واحد من Starlette عند استخدام httpx في TestClient؛ الاختبارات نجحت. هذا تحذير اعتماد اختباري وليس خطأ تشغيل مثبتًا. Runtime dependencies الدقيقة في requirements.txt.

## فحوص الواجهة

- نجح `node --check` لكل main.js وadmin.js وpreferences.js.
- المعرّفات HTML المستخدمة بواسطة JavaScript موجودة وغير مكررة؛ أزواج سمات الترجمة العربية/الإنجليزية موجودة.
- مراجعة فعلية للرئيسية بالعربية في الوضع الفاتح وبالإنجليزية في الداكن.
- مراجعة واجهة بعرض 390px و768px داخل إطارات QA في المتصفح، بما فيها فتح المحادثة بالعربية.
- رُصد تجاوز عرض بسبب الرسم المتحرك وأُصلح. بعد الإصلاح كان عرض body وعرض التمرير متساويين 375px عند إطار 390px مع شريط تمرير رأسي.
- مراجعة شاشة دخول الإدارة بصريًا.
- التحقق من تحميل IBM Plex Sans Arabic فعليًا محليًا، وظهوره كخط body مع fonts.check=true.

**حد المعاينة:** بيئة المعاينة البصرية لا تشغّل Python، لذلك كانت معاينة المتصفح للأصول الثابتة. ظهر خطأ اتصال متوقع في أقسام البيانات أثناء هذه المعاينة. اختبارات API وقواعد البيانات نُفذت عبر TestClient الحقيقي بصورة منفصلة؛ لم ندّع اختبار رحلة متصفح كاملة من الدخول إلى الحفظ على خادم حي. لا تشمل ملفات التسليم صفحة QA أو بيانات اختبار.

## ما يحتاج بيئة السيرفر

- بناء وتشغيل Docker: Docker غير متاح هنا؛ روجعت الملفات دون الادعاء بنجاح docker build.
- Coolify وTLS وDNS وربط v7.samideveloper.com، وضبط شبكة البروكسي والعنوان الحقيقي للعميل.
- حفظ البيانات عبر إعادة إنشاء الحاوية على Volume فعلي. اختبارات إعادة التشغيل الحالية محلية مع SQLite.
- تكامل n8n الحقيقي، مفاتيح Webhook، Gemini، Qdrant والذاكرة. لا تحتوي الحزمة أسرارًا أو Workflow صادرًا من سيرفرك.
- رحلة المتصفح الكاملة للإدارة والرفع والنماذج مع الخادم المنشور، وأجهزة iOS/Android الفعلية.
- Lighthouse أو أرقام سرعة ميدانية واختبار حمل؛ لا توجد أرقام أداء مختلقة.

## القيود المتبقية المعروفة

1. النصوص القديمة دون ترجمة إنجليزية تُعرض بالنص المتاح؛ يجب إدخال ترجمتها من الإدارة، ولا توجد ترجمة تلقائية للمحتوى.
2. Architect يتطلب من وكيل n8n الالتزام ببنية JSON الموثقة. إن خالفها سيظهر خطأ بدل عرض تحليل غير موثوق.
3. منع المعلومات المالية يعتمد على تعليمات وفحص نصي؛ ليس تصنيفًا دلاليًا مستقلًا. لا توجد حقول أسعار أو دفع في التطبيق.
4. حد الطلبات داخل ذاكرة عملية واحدة؛ يلزم حد مشترك عند التوسع أو على البروكسي.
5. ملفات PDF تُفحص بالحجم والتوقيع وتُنزل بشكل خاص؛ لا يوجد ماسح برمجيات خبيثة.
6. لا توجد إعادة محاولة آلية لإشعار n8n الفاشل؛ الطلب محفوظ وحالة الإشعار ظاهرة.
7. ملاحظات المعرفة محلية، لا تُفهرس تلقائيًا في Qdrant.
8. روابط صفحات المشاريع والمقالات مستقلة غير مضافة؛ التفاصيل تظهر داخل الصفحة عبر بطاقات قابلة للتوسيع.
9. مرفق واحد لكل طلب بحد 5MiB، كما توضّح الواجهة.
10. المصادر القديمة غير النشطة في legacy_v7 للمرجع، وليست جزءًا من التشغيل أو الاختبارات الحالية.
