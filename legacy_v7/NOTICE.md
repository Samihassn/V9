# مرجع V7 غير نشط

هذه الملفات كانت مسار تطبيق آخر (`main.py`) لا يشغّله Docker المرفق أصلًا، واختباراته لا تختبر `app.py`.
حُفظت للرجوع والمقارنة ولا يتم تضمينها في صورة Docker. ملفات Python مؤرشفة بامتداد `.txt` لمنع تشغيلها أو جمع اختباراتها خطأً.
التطبيق الموحد في V8 هو `app.py`، و`main.py` الحالي يعيد تصديره للتوافق مع إعدادات التشغيل.
الاختبارات الصحيحة موجودة في `tests/`. احتفظ أيضًا بملف ZIP الأصلي للرجوع الكامل.
