# SAMI DEVELOPER V7 — حزمة مستقلة للتشغيل والاختبار

## المحتوى
- موقع عربي RTL بتصميم Dark Emerald ومتجاوب.
- عرض الخدمات والمشاريع والتكاملات ومركز مقالات.
- Automation Lab: **محاكاة مرئية فقط**.
- SAMI AI: ربط اختياري بـ n8n/Gemini/Qdrant عبر webhook.
- AI Solution Architect وAI Playground (تلخيص/استخراج/تحسين نصوص): تستخدم webhook المساعد نفسه.
- نموذج طلب مشروع بدون حسابات أو أسعار، محفوظ في SQLite.
- إشعار n8n اختياري للطلبات الجديدة عبر webhook مستقل.
- لوحة إدارة خاصة: جلسة HttpOnly، طلبات العملاء، حالات الطلبات، مشاريع، رفع صور، مقالات، نصوص الصفحة، ملاحظات معرفة محلية.
- صفحة حالة إعدادات النظام.

## التشغيل محليًا عبر Docker
1. فك الضغط في مجلد جديد منفصل عن المشروع القديم.
2. انسخ `.env.example` إلى `.env`.
3. غيّر `ADMIN_TOKEN` إلى قيمة عشوائية لا تقل عن 32 حرفًا. مثال توليد: `python -c "import secrets;print(secrets.token_urlsafe(48))"`.
4. ضع `SAMI_N8N_WEBHOOK_URL` و`SAMI_N8N_API_KEY` إذا أردت تفعيل المساعد.
5. شغّل `docker compose up -d --build`.
6. على نفس جهاز Docker افتح `http://localhost:8087`، ولوحة الإدارة `http://localhost:8087/admin`.
7. اعرض السجلات عبر `docker compose logs -f web`.
8. للتحقق: `curl http://localhost:8087/api/health`.

## ربط n8n
- Webhook POST يستقبل `{"message":"...","sessionId":"..."}`.
- يرد JSON بالشكل `{"reply":"..."}`.
- يُرسل المفتاح في Header: `X-SAMI-AI-KEY`.
- يدعم HTTPS، أو HTTP الداخلي باسم حاوية Docker يبدأ بـ `n8n-` على المنفذ 5678.
- إذا لم تكن الخدمة على شبكة Docker مشتركة، اربط الشبكات أولًا.
- إشعارات الطلبات تحتاج webhook منفصلًا: `SAMI_N8N_REQUESTS_URL` و`SAMI_N8N_REQUESTS_KEY`؛ تُرسل بيانات العميل بعد موافقته في النموذج. لا تعتمد على الإشعار وحده: الطلب محفوظ محليًا.

## Coolify
- أنشئ تطبيقًا تجريبيًا **جديدًا** بدل استبدال الموقع الحالي.
- استخدم Dockerfile، والمنفذ الداخلي 8000، واضبط الدومين التجريبي المنفصل.
- أضف أسرار البيئة من واجهة Coolify، ولا ترفع `.env` إلى GitHub.
- اربط تخزينًا دائمًا إلى `/app/data` حتى تبقى الطلبات والصور والمقالات بعد إعادة التشغيل.
- استخدم HTTPS قبل استعمال لوحة الإدارة أو جمع بيانات حقيقية.
- لا تلمس `samideveloper.com` أو `main` قبل اختبار التطبيق وموافقتك.

## مهم قبل إطلاق الإنتاج
- الحزمة **إصدار مرشح للاختبار** وليست نسخة منشورة أو معتمدة أمنيًا. لم يُختبر Docker/Coolify على سيرفرك.
- يلزم سياسة خصوصية مناسبة، وتحديد مدة الاحتفاظ ببيانات العملاء، ومراقبة النسخ الاحتياطي.
- يفضّل وضع لوحة الإدارة خلف Cloudflare Access أو حماية إضافية وMFA.
- الحد من الطلبات الحالي داخل ذاكرة عملية واحدة فقط، وليس بديلًا عن rate limiting عند Cloudflare/Proxy.
- رفع الصور يقيّد نوع الملف وحجمه ويفحص الترويسة، لكن يُفضّل إعادة ترميز الصور وفحصها قبل الاستخدام العام.
- ملاحظات المعرفة محلية ولا تتم مزامنتها تلقائيًا إلى Qdrant.
- لا يوجد مراقب تنفيذ n8n/Qdrant حي، ولا جدولة نشر، ولا دعم رفع مرفقات العملاء، ولا فيديوهات مشاريع مباشرة.
- تجنب إدخال بيانات شخصية حساسة في AI Playground؛ النصوص تُرسل إلى n8n عند تفعيل الربط.
- SAMI AI يعتمد على أن n8n يطبق قواعد السلامة والخصوصية والتحكم بالوصول.
